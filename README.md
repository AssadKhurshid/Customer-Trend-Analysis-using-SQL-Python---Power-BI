# 📊 Customer Trends Data Analysis

An end-to-end data analytics project simulating a real-world corporate workflow — transforming raw customer data into actionable business intelligence using **Python, SQL, and Power BI**.

---

## 📌 Project Overview

This project demonstrates the complete analytics lifecycle:

- ✅ **Data Preparation & EDA (Python)**  
  Clean, transform, and explore raw customer data.

- ✅ **Data Analysis (SQL)**  
  Simulate business transactions and extract insights on customer segments, loyalty, and purchase drivers.

- ✅ **Visualization (Power BI)**  
  Build an interactive dashboard highlighting trends and KPIs.

- ✅ **Reporting & Presentation**  
  Summarize key findings and provide strategic business recommendations.

The objective is to showcase how raw data can be converted into meaningful, decision-ready insights.

## 🚀 How to Run This Project

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/amlanmohanty1/customer-trends-data-analysis-SQL-Python-PowerBI.git
cd customer-trends-data-analysis-SQL-Python-PowerBI](https://github.com/AssadKhurshid/Customer-Trend-Analysis-using-SQL-Python---Power-BI
```

---

### 2️⃣ Python Data Analysis

Open the notebook:

```
Customer_Shopping_Behavior_Analysis.ipynb
```

This notebook contains:
- Data import  
- Data exploration  
- Data cleaning and transformation  
- SQL database connection setup  

---

### 3️⃣ Load Data into SQL

1. Create a new database (MySQL / PostgreSQL / MS SQL Server).
2. Run the Python notebook to load the cleaned dataset into your SQL database.
3. Open the SQL file:

```
customer_behavior_sql_queries.sql
```

4. Execute queries to answer business questions and extract insights.

---

### 4️⃣ Power BI Dashboard

1. Connect Power BI to your SQL database.
2. Open:

```
customer_behavior_dashboard.pbix
```

3. Explore the interactive dashboard to analyze customer trends and KPIs.

---

- Create a detailed project report summarizing analysis and insights.
